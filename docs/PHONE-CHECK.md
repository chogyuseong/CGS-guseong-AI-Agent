# 폰에서 직접 확인할 것

자동화(Playwright)로 볼 수 없거나 실제 기기·계정이 있어야 하는 것을 한곳에 모은 체크리스트다.
화면 폭(360·390·768·1280px)의 가로 스크롤·화면 밖 요소·44px 버튼은 `apps/web/e2e/widths.spec.ts`가 자동으로 본다(9단계 1번).
여기에는 그 밖의 것, 특히 **키보드가 올라온 상태**를 적는다.

## 준비

- 같은 와이파이에서 열기: `apps/web/README.md`의 "폰에서 접속하기"(`.env`의 `APP_ORIGIN`을 PC의 LAN 주소로).
- 푸시·음성 입력처럼 https가 필요한 것: `docs/PUSH-CHECK.md` 3절의 터널(https 주소). 끝나면 터널을 끄고 `APP_ORIGIN`을 되돌린다.
- 확인 기기: 안드로이드 Chrome 1대, 가능하면 아이폰 Safari(홈 화면에 추가한 앱) 1대.
- 실제 모델을 부르는 항목(채팅 요청)은 비용이 든다. 몇 번만 보낸다.

## 1. 키보드가 올라온 상태 (9단계, 자동화로 확인 불가)

### 채팅 입력창
- [ ] 입력창을 누르면 키보드가 올라오고 입력창이 키보드 바로 위에 보인다(키보드에 가리지 않는다).
- [ ] 아이폰에서 입력창을 눌러도 화면이 확대되지 않는다(글자 16px).
- [ ] 키보드가 올라온 채로 마지막 메시지가 입력창 위에 보인다. 위로 스크롤하면 예전 메시지를 볼 수 있다.
- [ ] 여러 줄을 입력하면 입력창이 늘어나다가 일정 높이(약 160px)부터는 입력창 안에서 스크롤된다. 전송 버튼이 화면 밖으로 밀리지 않는다.
- [ ] 키보드가 올라와 있을 때 하단 탭이 입력창을 가리거나 입력창과 겹치지 않는다(안드로이드는 하단 탭이 키보드 위로 따라 올라올 수 있다. 입력창이 보이면 정상).
- [ ] 전송하면 입력창이 비고, 키보드를 내렸다 올려도 화면 높이가 어긋나지 않는다(빈 띠가 남지 않는다).
- [ ] 아이폰: 화면 위쪽(노치·상태 표시줄)과 아래쪽(홈 바)에 내용이 가리지 않는다.

### 승인 카드
- [ ] 키보드가 올라온 상태에서 승인 카드가 나타나도(답변 자리) 스크롤해서 카드 전체를 볼 수 있다.
- [ ] 키보드를 내리지 않고 [승인]·[거절]을 누를 수 있고, 한 번 누르면 바로 막힌다(두 번 눌리지 않는다).
- [ ] mismatch(빨간 "요청과 다를 수 있음") 카드에서 [승인] → "그래도 진행할까요?"가 키보드에 가리지 않고 보인다(열릴 때 보이는 곳까지 스크롤된다).
- [ ] [입력값 보기]를 펼쳐도 카드가 화면 밖으로 넘치지 않는다.

### 그 밖의 입력칸
- [ ] 로그인: 이메일 → 비밀번호로 넘어갈 때 키보드가 [로그인] 버튼을 가리면 스크롤해서 누를 수 있다. 비밀번호 저장 제안이 화면을 깨지 않는다.

## 2. 로그인 (0단계)
- [ ] `create-user`로 만든 계정으로 폰 브라우저에서 로그인된다.
- [ ] 틀린 비밀번호면 한국어 오류가 보인다.
- [ ] 로그인 뒤 새로 고침해도 로그인이 유지된다.

## 3. 채팅과 작업 단계 (1·3단계)
- [ ] '우유 사기 할 일에 추가해줘' → 답변 아래 단계 타임라인에 단계가 보이고, 누르면 입력·출력이 펼쳐진다.
- [ ] 답변을 기다리는 동안 "곧 시작합니다 → 작업하는 중"이 보이고, 다른 앱에 갔다 와도 같은 자리에서 이어진다.
- [ ] 왼쪽 위 대화 목록 버튼 → 시트가 열리고 [새 대화]·대화 고르기·닫기(X)가 손가락으로 잘 눌린다.
- [ ] 작업 기록 탭에서 같은 작업을 펼치면 같은 단계가 보인다.
- 서버를 작업 도중 끄고 다시 켰을 때 이어서 끝나는지: `docs/DURABILITY-CHECK.md`.

## 4. 승인 카드 (2·4단계)
- [ ] '이번 주 금요일 저녁 7시에 성수동에서 저녁 약속 잡아줘' → 승인 카드에 preview 문장, 초록 "요청과 일치" 배지, [승인]·[거절](높이 48px, 폭 전체).
- [ ] [승인] → 실제 Google 캘린더에 일정이 1개만 생긴다. [거절]이면 생기지 않는다.
- [ ] 남은 시간("…까지 결정해 주세요 · N분 남음")이 보인다.

## 5. 알림 켜기와 푸시 수신 (3단계)
- 절차 전체: `docs/PUSH-CHECK.md`(4절 "폰에서 받아 보기", 6절 "폰에서").
- [ ] 설정 탭 → [알림 켜기] → 권한 허용 → 배지 '켜짐'.
- [ ] 앱을 닫은 채로 '승인이 필요한 작업이 있습니다' 푸시가 오고, 누르면 그 대화가 열린다.
- [ ] 푸시 문구에 대화 내용·일정 제목이 없다.
- [ ] 아이폰은 홈 화면에 추가한 앱에서만 켜진다(Safari 탭에서는 '지원 안 함'과 안내).

## 6. 음성 입력 (7단계)
- [ ] 마이크 버튼은 지원 브라우저(안드로이드 Chrome 등)에서만 보인다. 지원하지 않으면 버튼이 없다.
- [ ] https 주소(터널)에서 마이크 → 권한 허용 → 한 문장 말하기 → 입력창 끝에 글자가 들어가고 **자동으로 보내지 않는다**.
- [ ] 듣는 중에는 빨간 정지 모양과 "듣는 중…" 안내, 다시 누르면 멈춘다.
- [ ] `http://192.168…`(같은 와이파이)에서는 권한이 막히고 "https 주소에서만" 안내가 나온다.
- [ ] 키보드가 올라온 채로 마이크를 눌러도 입력창·버튼이 가리지 않는다.

## 7. Google 연결과 메일 읽기 (4·7단계)
- [ ] 설정 → Google 계정 연결 → [Google 계정 연결] → Google 동의 화면(캘린더만 요청) → 돌아오면 "연결했습니다" 안내와 '연결됨'.
- [ ] [메일 읽기 권한 추가] → 동의 화면에 Gmail 읽기 항목이 있다('확인되지 않은 앱' 경고가 뜨면 고급 → 이동). 돌아오면 "메일 읽기 권한을 추가했습니다"와 메일 권한 '있음'.
- [ ] 동의 화면에서 Gmail 항목만 빼고 허용하면 "메일 읽기 권한을 허용하지 않아…캘린더 연결은 그대로" 안내, 메일 권한 '없음'.
- [ ] '오늘 온 메일 요약해줘' → 메일 단계가 타임라인에 보이고, 펼치면 "작업 기록에는 메일 내용을 앞 500자만 보관합니다".
- [ ] [연결 해제] → 화면 안에서 한 번 더 묻고 해제된다. 해제 뒤 Google 계정의 '타사 앱 액세스'에서도 사라진다.
- [ ] 약 7일 뒤(테스트 상태 앱) 연결이 풀리면 이 화면에서 다시 연결할 수 있다.

## 8. 기억 (5단계)
- [ ] '나 매운 거 못 먹어, 기억해' → 기억 탭에 1건, [원래 메시지 보기]로 내가 한 말이 보인다.
- [ ] 새 대화에서 식당 추천에 반영된다. 기억을 지우면 반영되지 않는다.
- [ ] [전체 삭제]는 화면 안에서 한 번 더 묻는다.

## 9. 자동화와 아침 브리핑 (6단계)
- [ ] 자동화 탭에 아침 브리핑(07:30)이 보이고 켜기·끄기 스위치·[삭제]가 손가락으로 잘 눌린다.
- [ ] 07:30에 브리핑 푸시가 오고, 누르면 '예약 작업' 대화방이 열린다.
- [ ] 브리핑 답변의 [제안] 버튼은 누를 때만 그 문장을 보내고, 일정처럼 바뀌는 일은 다시 승인을 묻는다.
- [ ] '내일 서울에 비 올 확률이 60% 넘으면 알려줘' → 자동화 탭 감시 목록에 보인다.

## 10. 화면 전반 (9단계)
- [ ] 폰을 가로로 돌려도 가로 스크롤이 생기지 않고 하단 탭을 누를 수 있다.
- [ ] 홈 화면에 추가한 앱에서 상태 표시줄 색이 화면 배경과 같다(밝음: 흰색, 어둠: 거의 검정).
- [ ] 홈 화면 아이콘이 어두운 바탕에 흰 "MA"로 보인다. 안드로이드에서 아이콘 모양(원·둥근 사각형)이 바뀌어도 글자가 잘리지 않는다(maskable). 아이폰 아이콘도 같은 그림이다(apple-touch-icon).

### 다크 모드 (9단계 보강)
앱은 폰의 시스템 설정(다크 모드)을 따른다. 앱 안에는 테마 선택이 없다. 자동 점검(e2e/dark-mode.spec.ts, 360px 어둠·밝음 대비 측정)은 통과했고, 아래는 실기기로만 볼 수 있는 것이다.
- [ ] 폰을 다크 모드로 바꾸면 앱을 다시 열지 않아도 화면이 어두워진다(돌아오면 밝아진다).
- [ ] 첫 화면이 열릴 때 흰 화면이 번쩍이지 않는다.
- [ ] 채팅: 내 말풍선·답변·단계 타임라인(완료 체크, 승인 대기·결과 확인 필요 글자)·외부 콘텐츠 상자·메시지 초안 카드가 어두운 바탕에서 읽힌다.
- [ ] 승인 카드: "AI 검토" 배지(일치·다를 수 있음)와 빨간 경고 문장, [승인]·[거절] 버튼 글자가 읽힌다.
- [ ] 입력창에 글자를 쓸 때 글자·안내 문구·커서가 보이고, 키보드도 어두운 키보드로 뜬다(폰 설정에 따름).
- [ ] 자동화·기억·설정·연결·비용 화면과 대화 목록 시트, 음성 입력 안내가 어두운 바탕에서 읽힌다.
- [ ] 햇빛 아래 최대 밝기·최저 밝기에서 회색 안내 글자가 읽히는지 본다.
