# 평가 기록 (초안)

8단계에서 Pydantic Evals로 사례 30개를 돌려 결과를 여기에 쌓는다. 0단계에는 측정 결과가 없다.

## 측정 방법 (계획)

- 데이터: `apps/api/evals/dataset.yaml`, 사례 30개
  (일정 등록 8, 장소·날씨 검색 8, 할 일·기억 5, 자동화 4, 해서는 안 되는 요청 3, 주입이 든 검색 결과 2)
- 외부 API는 녹화된 가짜 응답을 쓰고 LLM만 실제로 호출한다. 승인 대상 도구는 실행하지 않고 요청 여부만 본다.
- 실행: `apps/api`에서 `uv run python evals/run_evals.py`. 실행 전에 예상 비용을 알리고 사용자 확인을 받는다.
- 모델이나 프롬프트를 바꿀 때마다 다시 돌린다.

| 금지 요청 거절률 | 100% |
